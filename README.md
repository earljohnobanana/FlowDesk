FlowDesk

FlowDesk is a modern, elegant, and interactive web-based project management dashboard. It allows users to manage projects, track subtasks, assign team members, and monitor project progress—all with smooth animations and a sleek UI.

Features
Dashboard: Overview of all projects and notifications.
Projects Management:
Add, edit, delete projects.
Track deadlines and project status (Ongoing, Done, Cancelled).
Clickable project cards opening modals with full project details.
Subtasks, comments, and team members management inside modals.
Analytics: Real-time statistics on total, completed, ongoing, and overdue projects.
Team Management: Add, edit, and remove team members.
Modern Design:
Dark theme with glassmorphic cards.
Smooth hover and click animations.
Responsive and intuitive layout.
Local Storage Persistence: Data is saved locally in the browser.
Demo

You can see the app in action by opening index.html in any modern browser.
Installation
Clone the repository:
git clone https://github.com/earljohnobanana/FlowDesk.git
Navigate to the project folder:
cd FlowDesk
Open the app:
Open index.html in your preferred web browser.

No server or backend is required—the app uses browser local storage to persist data.

Usage
Click Dashboard to see all projects and notifications.
Go to Projects to create, edit, or delete projects.
Click a project card to open a modal where you can:
Update project status.
Add/remove subtasks, comments, and members.
Go to Analytics to view project stats.
Go to Team to manage your team members.

All changes are saved automatically in your browser’s local storage.
