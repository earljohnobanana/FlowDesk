🌊 FlowDesk

FlowDesk is a modern, elegant, and interactive web-based project management dashboard. It helps users manage projects, track subtasks, assign team members, and monitor project progress—all with smooth animations and a sleek UI.

🚀 Features

📊 Dashboard
Overview of all projects and notifications.
Interactive project cards that open detailed modals.

📁 Projects
Add, edit, delete projects.
Track deadlines and project status (Ongoing, Done, Cancelled).
Manage subtasks, comments, and team members directly in modals.

📈 Analytics
Real-time statistics: total projects, completed, ongoing, and overdue.

👥 Team Management
Add, edit, and remove team members.
Display members elegantly with their roles.

🎨 Modern Design
Dark theme with glassmorphic cards.
Smooth hover and click animations.
Responsive layout with intuitive UX.

💾 Local Storage
Persistent project and team data saved in the browser.

🎬 Demo

Open index.html in any modern browser to see FlowDesk in action.





⚡ Installation
Clone the repository
git clone https://github.com/earljohnobanana/FlowDesk.git
Navigate to the folder
cd FlowDesk
Open the app
Open index.html in your preferred browser.
No server required—data is stored in local storage.
🛠 Usage
Dashboard: View all projects and notifications.
Projects: Create, edit, or delete projects. Click a project card to:
Update project status.
Add/remove subtasks, comments, and members.
Analytics: See project stats in real-time.
Team: Manage your team members.

All changes are saved automatically in the browser.
